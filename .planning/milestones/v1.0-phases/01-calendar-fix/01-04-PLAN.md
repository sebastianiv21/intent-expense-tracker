**Surface 2: Budgets page (budgets-page.tsx)**
10. Navigate to the Budgets section and open the "Add budget" or "Edit budget" form
11. Tap the start date trigger ("Start date")
12. Confirm: Calendar opens inline with compact sizing (same visual as transaction sheet)
13. Select a date and confirm the calendar closes

**Surface 3: Recurring transactions page (recurring-page.tsx)**
14. Navigate to the Recurring section and open the "Add recurring" or "Edit recurring" form
15. Tap the "Start date" trigger — confirm inline calendar opens
16. Select a start date
17. Tap the "End date (optional)" trigger — confirm its own independent inline calendar opens
18. Confirm: End date calendar does NOT allow selecting a date before the start date
19. Select an end date and confirm the calendar closes

20. Resize browser to 1280px wide (or any desktop viewport)
