## Spacing Scale

Declared values (multiples of 4 — standard 8-point scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chevron-to-amount gap |
| sm | 8px | Inline gap between badge and amount text |
| md | 16px | Card padding (existing `p-4`) |
| lg | 24px | Section spacing between date groups |
| xl | 32px | Page-level layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch target minimum: 44px — the existing dropdown trigger uses `min-h-11 min-w-11` (44px). The chevron toggle button MUST also use `min-h-11 min-w-11` to comply.
- Detail row internal padding: `pt-2` (8px top) to visually separate from the main row — no additional indentation.
- Detail row left indent: `pl-[52px]` — computed layout alignment: 40px category icon + 12px gap = 52px. Not a scale multiple; justified by icon geometry.

Source: Observed in `transaction-item.tsx` line 64 (existing `min-h-11 min-w-11`); 8-point scale is project default.

## Typography

| Role | Size | Weight | Line Height | Tailwind class |
|------|------|--------|-------------|----------------|
| Body / primary label | 14px (sm) | 400 (regular) | 1.5 | `text-sm` |
| Amount (primary) | 14px (sm) | 600 (semibold) | 1.4 | `text-sm font-semibold` |
| Secondary label / date | 12px (xs) | 400 (regular) | 1.4 | `text-xs text-muted-foreground` |
| Detail row (expansion) | 12px (xs) | 400 (regular) | 1.4 | `text-xs text-muted-foreground` |

Notes:
- Exactly 2 weights in use: 400 (regular) and 600 (semibold). No third weight.
- The amount line uses `font-semibold` (600) to establish hierarchy over the description and secondary labels, which both use the default weight (400).
- The expanded detail row uses `text-xs text-muted-foreground` — identical to the existing date line. This keeps conversion metadata visually secondary to the primary transaction amount.
- The amount line stays `text-sm font-semibold` whether showing original-currency or base-currency value. Font size does NOT change for foreign-currency items.
- No new font sizes introduced — this phase reuses the two sizes already present in `TransactionItem`.

Source: Observed in `transaction-item.tsx` lines 41-57; pattern confirmed from CONTEXT.md `<specifics>` section.

## Component Inventory

This phase modifies ONE existing component and ONE utility. No new components.

### Modified: `web/components/transaction-item.tsx`

**State added:**
```
const [expanded, setExpanded] = useState(false);
```
Local only — no context, no URL param (CONTEXT.md D-07).

**New imports:**
```
import { useState } from "react";
import { ChevronDown, ChevronUp } from "lucide-react";
import { formatCurrency as formatCurrencyRaw } from "@/lib/finance-utils";
```
`ChevronDown`/`ChevronUp` are from `lucide-react` — already a project dependency. `MoreHorizontal` already imported from same package.

**Hook extension:**
```
const { formatCurrency: formatBase, currency: baseCurrency } = useCurrency();
```
Rename `formatCurrency` → `formatBase` to avoid name collision with the raw import (CONTEXT.md code snippet).

**Amount display logic:**
- `isForeign = transaction.currency !== baseCurrency`
- If `isForeign`: display `formatCurrencyRaw(transaction.originalAmount, transaction.currency)`
- If same currency: display `formatBase(transaction.amount)` — unchanged behavior (CONTEXT.md D-01, D-02)
- Sign prefix unchanged: expense → `-`, income → `+` (CONTEXT.md D-03)

**Chevron placement:**
- Rendered only when `isForeign === true`
- Placed between the amount text and the `DropdownMenu` trigger — inside the trailing `flex items-center gap-2` div
- Uses `Button variant="ghost" size="icon"` with `min-h-11 min-w-11` to meet touch target minimum
- Icon: `ChevronDown` when collapsed, `ChevronUp` when expanded; both at `h-4 w-4`
- `aria-expanded={expanded}` on the button
- `aria-label="Show conversion details for {transaction.description || transaction.category?.name || 'transaction'}"`

**Click area:**
- The chevron `Button` handles its own click — `onClick={() => setExpanded(prev => !prev)}`
- The card's outer `div` does NOT receive a click handler — click-to-expand is chevron-only, not whole-card, to avoid interference with the existing `hover:bg-muted/30` interaction (CONTEXT.md D-09)

**Expanded detail row:**
- Rendered below the main `flex` row when `expanded === true` and `isForeign === true`
- Layout: single `div` with `pt-2 pl-[52px]` (left-indent to align with description text, clearing the 40px icon + 12px gap = 52px)
- Content (single line, wrapping allowed on narrow viewports):
  ```
  → {formattedBase} {baseCurrency}  ·  {invertedRate} {txCurrency}/{baseCurrency}  ·  {date}
  ```
  Example: `→ $12.50 USD  ·  4,098 COP/USD  ·  Apr 19, 2026`
- `formattedBase` = `formatBase(transaction.amount)` (base currency, 2 decimal places)
- `invertedRate` = `Math.round(1 / parseFloat(transaction.exchangeRate)).toLocaleString("en-US")` (e.g., "4,098") (CONTEXT.md D-10, D-11)
- Date = `format(parsedDate, "MMM d, yyyy")` — same `date-fns` pattern used in the existing date sub-label (CONTEXT.md D-08)
- Tailwind classes: `text-xs text-muted-foreground`

**Note on rate display separator:** CONTEXT.md D-08 uses `@` as the rate separator. This spec uses `·` (middle dot) for visual consistency with the existing date sub-label separator pattern already present in the codebase. Either is acceptable — executor may use `@` if they prefer to match the CONTEXT.md example exactly. Both are conformant.

### Modified: `web/lib/finance-utils.ts`

**Function:** `getCurrencyFormatter` (lines 53-65)

**Change:** Replace hardcoded `minimumFractionDigits: 2, maximumFractionDigits: 2` with `getCurrencyDecimals(currency)` for both fields.

**Constraint:** `getCurrencyDecimals` is defined at line 113 — below `getCurrencyFormatter`. Move `getCurrencyDecimals` above `getCurrencyFormatter` (or hoist with a forward reference pattern) so the call is valid at parse time (CONTEXT.md D-12).

**No change to:** `getCompactCurrencyFormatter` — it uses `maximumFractionDigits: 1` with `notation: "compact"`, which already produces acceptable compact COP display (CONTEXT.md D-13).

**Safety:** `getCurrencyDecimals("USD")` returns `2` — zero behavioral change for USD (CONTEXT.md D-14).

## Interaction Contract

### State Machine: TransactionItem (foreign-currency)

```
COLLAPSED (default)
  ├── amount: originalAmount in txCurrency (e.g., -COL$50.000)
  ├── chevron: ChevronDown (accent color)
  └── detail row: hidden

  user clicks chevron
        ↓

EXPANDED
  ├── amount: unchanged (still originalAmount in txCurrency)
  ├── chevron: ChevronUp (accent color)
  └── detail row: visible
      "→ $12.50 USD  ·  4,098 COP/USD  ·  Apr 19, 2026"

  user clicks chevron again
        ↓

COLLAPSED (back to default)
```

### State Machine: TransactionItem (same-currency / USD)

```
STATIC (no state)
  ├── amount: formatBase(transaction.amount) — unchanged from today
  ├── chevron: absent
  └── detail row: absent
```

No regression to existing USD items.
