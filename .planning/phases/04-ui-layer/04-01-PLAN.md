<objective>
Fix the `getCurrencyFormatter` factory in `web/lib/finance-utils.ts` to use per-currency decimal places instead of the hardcoded `2`.

Purpose: COP is a zero-decimal currency. The current formatter always produces `COL$50.000,00` for COP amounts. After this fix, `getCurrencyDecimals("COP")` returns `0` and `getCurrencyDecimals("USD")` returns `2`, so formatters are built with the correct precision per currency. This is a prerequisite for Plan 02: the `formatCurrencyRaw(originalAmount, "COP")` call in `TransactionItem` must produce `COL$50.000` (0 decimals) before the list display satisfies DISP-01.

Output: Modified `web/lib/finance-utils.ts` — `getCurrencyDecimals` moved above `getCurrencyFormatter`; factory uses `getCurrencyDecimals(currency)` for both `minimumFractionDigits` and `maximumFractionDigits`.
</objective>
